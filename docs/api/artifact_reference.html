Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /content/references create List of references detected in the provided content. Each reference will have only the name field populated. The name value corresponds to the reference string found in the content (for example a JSON Schema $ref value, a Protobuf import path, or an Avro type name)
GET /groups/{groupId}/artifacts/{artifactId}/versions/{versionExpression}/references list List of all the artifact references for this artifact
GET /ids/globalIds/{globalId}/references list A list containing all the references for the artifact with the given global id
GET /ids/contentHashes/{contentHash}/references list A list containing all the references for the artifact with the given content hash
GET /ids/contentIds/{contentId}/references list A list containing all the references for the artifact with the given content id

GET /groups/{groupId}/artifacts/{artifactId}/versions/{versionExpression}/references

Operation ID: getArtifactVersionReferences.

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | groupId | path | string | Yes | The artifact group ID. Must be a string provided by the client, representing the name of the grouping of artifacts. Must follow the ".{1,512}" pattern. | | artifactId | path | string | Yes | The artifact ID. Can be a string (client-provided) or UUID (server-generated), representing the unique artifact identifier. Must follow the ".{1,512}" pattern. | | versionExpression | path | string | Yes | An expression resolvable to a specific version ID within the given group and artifact. The following rules apply: - If the expression is in the form "branch={branchId}", and artifact branch {branchId} exists: The expression is resolved to a version that the branch points to. - Otherwise: The expression is resolved to a version with the same ID, which must follow the "[a-zA-Z0-9._\-+]{1,256}" pattern. | | refType | query | enum: OUTBOUND, INBOUND | No | Determines the type of reference to return, either INBOUND or OUTBOUND. Defaults to OUTBOUND. |
