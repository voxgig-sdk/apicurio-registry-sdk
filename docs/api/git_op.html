Operation ID: createGitOpsValidateTask.

Request body

application/json

Property Type Required Description
ref string Yes Git ref to validate (branch name, tag, or PR ref like refs/pull/42/head).
repoId string Yes Repository ID to validate against. Must match a configured repository.
type enum: pull No Validation type. Currently only pull is supported.

Responses

202: Validation task created. Poll the task status to get the result

application/json

Property Type Required Description
artifactCount integer (int32) No Number of artifacts loaded during validation. Only present when state is completed.
completedAt string (date-time) No ISO 8601 timestamp of when the task completed. Only present when state is completed or failed.
createdAt string (date-time) No ISO 8601 timestamp of when the task was created.
errors array of object No Validation errors. Empty if validation passed.
errors[].context string No The file path or location where the error occurred. Absent if the error is not file-specific.
errors[].detail string Yes A human-readable description of the error.
errors[].source string No The source ID (for example, repository ID) where the error occurred. Absent for global errors not tied to a specific source.
groupCount integer (int32) No Number of groups loaded during validation. Only present when state is completed.
ref string No Git ref being validated.
repoId string No Repository ID being validated.
result enum: success, failure No Validation result: success (all checks passed) or failure (validation errors found). Only present when state is completed.
state enum: pending, submitted, fetching, validating, completed, failed Yes Current task state: pending (queued, waiting for capacity), submitted (request sent to sidecar), fetching (sidecar is cloning), validating (registry is loading and validating), completed (finished with results), failed (an error occurred).
taskId string Yes Unique identifier for the validation task.
type string No Validation type (pull or push).
versionCount integer (int32) No Number of artifact versions loaded during validation. Only present when state is completed.
