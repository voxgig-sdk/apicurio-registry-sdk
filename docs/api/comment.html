Operation ID: addArtifactVersionComment.

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | groupId | path | string | Yes | The artifact group ID. Must be a string provided by the client, representing the name of the grouping of artifacts. Must follow the ".{1,512}" pattern. | | artifactId | path | string | Yes | The artifact ID. Can be a string (client-provided) or UUID (server-generated), representing the unique artifact identifier. Must follow the ".{1,512}" pattern. | | versionExpression | path | string | Yes | An expression resolvable to a specific version ID within the given group and artifact. The following rules apply: - If the expression is in the form "branch={branchId}", and artifact branch {branchId} exists: The expression is resolved to a version that the branch points to. - Otherwise: The expression is resolved to a version with the same ID, which must follow the "[a-zA-Z0-9._\-+]{1,256}" pattern. |
