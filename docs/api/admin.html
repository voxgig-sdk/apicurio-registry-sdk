POST /admin/import

Operation ID: importData.

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | X-Registry-Preserve-GlobalId | header | boolean | No | If this header is set to false, global ids of imported data will be ignored and replaced by next id in global id sequence. This allows to import any data even thought the global ids would cause a conflict. | | X-Registry-Preserve-ContentId | header | boolean | No | If this header is set to false, content ids of imported data will be ignored and replaced by next id in content id sequence. The mapping between content and artifacts will be preserved. This allows to import any data even thought the content ids would cause a conflict. | | requireEmptyRegistry | query | boolean | No | Query parameter indicating whether the registry must be empty before allowing data to be imported.
