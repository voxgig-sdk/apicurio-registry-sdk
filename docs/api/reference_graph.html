GET /groups/{groupId}/artifacts/{artifactId}/versions/{versionExpression}/references/graph

Operation ID: getArtifactVersionReferencesGraph.

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | groupId | path | string | Yes | The artifact group ID. Must be a string provided by the client, representing the name of the grouping of artifacts. Must follow the ".{1,512}" pattern. | | artifactId | path | string | Yes | The artifact ID. Can be a string (client-provided) or UUID (server-generated), representing the unique artifact identifier. Must follow the ".{1,512}" pattern. | | versionExpression | path | string | Yes | An expression resolvable to a specific version ID within the given group and artifact. | | direction | query | enum: OUTBOUND, INBOUND, BOTH | No | The direction of references to include in the graph. Can be OUTBOUND (artifacts this version references), INBOUND (artifacts that reference this version), or BOTH. Defaults to OUTBOUND. | | depth | query | integer | No | The maximum depth of the reference graph to traverse. Can be 1, 2, 3, or 0 for unlimited. Defaults to 3. |
